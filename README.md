# Customer Shopping Behavior Analysis

## 📌 Problem
Analyze customer purchasing patterns to identify revenue drivers and improve business strategy.

## ⚙️ Tools Used
- Python (Pandas)
- SQL (PostgreSQL)
- Power BI

## 🔄 Process
1. Data Cleaning (handled missing values)
2. Feature Engineering (age groups, segmentation)
3. SQL Analysis (business queries)
4. Dashboard Creation

## 📊 Key Insights
- Subscription users spend 68% more
- Express shipping users spend more
- Female customers generate slightly higher revenue
- Loyal customers drive major revenue
